# FantAsta

Assistente interattivo per l'asta Fantacalcio 2026/27 di Sporting Madonna.

Funzioni principali:
- 600 crediti iniziali per squadra
- listone Fantacalcio reale
- gestione acquisti, crediti e slot
- rilanci e controrilanci live
- potenza d'acquisto stimata per ogni squadra sul giocatore selezionato
- analisi delle minacce e strategie di pressione
- salvataggio locale e backup JSON
- supporto offline tramite service worker
